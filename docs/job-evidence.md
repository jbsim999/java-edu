기업이 요구한 과제와 교육자가 제안한 과제를 구분한다. 객체 설계(`oop`), 자료구조 선택(`collections`), 실패 정책(`exceptions`), HTTP 계약(`modern-apis`), 경계·실패 테스트(`testing-design`), 공유 상태·타임아웃·취소(`concurrency`)를 공고에서 관찰한 주제와 연결했다. 실제 기업의 채용 과제가 아니다.

이 표본에는 Java 8·11·17·21의 사용 여부, records·sealed·virtual threads 또는 JUnit의 직접 요구를 입증하는 근거가 없다. 이 기능들의 교육 근거는 Java 또는 해당 도구의 공식 문서다.
