# Java Edu 기획안 v0.3

기준일 2026-10-12 (Asia/Seoul). 사용자가 승인한 교육 방향과 Windows 설치형 + 웹 교재 구성을 기록한다.

## 목표와 대상

Java 동작 원리를 이해하고 설계 선택을 설명하며 실제 서비스를 구현·검증하는 교육 프로그램을 만든다. 다른 언어 경험자의 전환 경로와 현직자의 심화 경로가 공통 교재를 공유한다. 완전 프로그래밍 입문 과정은 제외하되 OOP·타입 시스템·동시성은 깊게 학습한다. 코드 해석·결함 수정·근거 설명 진단으로 필요한 단원을 선택한다.

## 교육 범위

Java 명세, 도구의 공식 계약, 교육자의 설계 지침을 구분한다. OAuth2는 인가 규약, OIDC는 인증 계층, Spring Security는 그 구현을 지원하는 프레임워크다. JPA 명세·Hibernate 구현·Spring Data 추상화도 구분한다. SOLID·패턴 사용 개수 자체로 평가하지 않는다.

## 수업과 평가

모든 공개 수업은 이론 → 예시 → 문제풀이 → 실무 심화 → 웹 IDE 직접 코딩이다. 클래스 골격형은 구조·불변식·책임 설계, 메서드 본문형은 API·경계 처리·로직 구현에 사용한다. 이후 프로젝트형은 Java·XML·SQL·설정 등 여러 파일을 다룬다. 외부 호출 계약은 명시하고 내부 설계 선택권을 둔다.

웹 IDE는 코드 보존·실행·피드백·수정·제출을 연결한다. 샘플 실행과 제출 검증, 실행 성공과 행동 테스트 통과, 설계 설명 기록과 설계 검토 완료를 구분한다. 코드가 바뀌면 이전 결과를 현재 코드의 성취로 표시하지 않는다.

## 버전·실무 근거

교육 버전 8·11·17·21, 최초 정식 도입 버전·최소 예제 버전·실제 실행 JVM을 구분한다. preview/incubator는 기본 과정에서 제외한다. Java8/11의 기존 Spring 세대와 Java17/21 현대 Spring 세대는 검증한 의존성 조합으로 분리한다. 기술적 호환성과 유지보수 지원은 별도다.

공고는 관찰 표본이다. 기업·직무·URL·확인일·모집 상태·필수/우대·접근 범위를 기록한다. 수업 연결은 교육자의 제안이며 시장 사용률이나 기업의 실제 채용 과제로 확대하지 않는다.

## 공개 범위와 확장

첫 **프로토타입**은 Java 코어 12개 수업, 두 종류의 실행 과제, 검색·버전·트랙·출처·진도·웹 IDE를 연결한다. 외부 실행 JVM은21이며 Java8/11/17/21 컴파일 대상 검증을 제공한다. 이것은 전체 과정이나 네 JVM 실행 서비스 완성본이 아니다.

후속 **실무 MVP**는 Spring·REST·Lombok·MyBatis·테스트의 대표 수업을 공개한다. 해당 라이브러리·다중 파일·DB·HTTP 실행 환경 검증이 공개 조건이다. 그 뒤 JPA·보안·캐시·메시징·운영 단원을 확장한다. 필요한 배포 계정·자원은 명시하고 비용·권한을 임의로 확대하지 않는다.

## 선택한 제품 구성

Windows 현재 사용자용 설치 앱과 웹 교재가 동일한 교육 화면을 공유한다. 코어12개와 실무22개 단원을 연결하고, 코드에는 Java 구문 색상과 다크·라이트·고대비 테마를 적용한다. 실무 단원의 Java/XML/SQL/설정 파일은 탭으로 탐색하며 학습자가 편집할 파일과 고정된 빌드·테스트를 구분한다.

설치형은 학습자가 등록한 로컬 JDK8/11/17/21와 Maven3.9+를 사용한다. 코드 실행은 PC에서 수행하고, 최초 환경 준비에서 고정된 Maven 의존성을 내려받은 뒤 과제는 오프라인으로 실행한다. 기본 DB는 H2이며 필수 Docker 서버를 요구하지 않는다. Redis/Kafka 실제 연동 단원에만 선택 자원을 안내한다. Gradle/Docker/CI 비교 자료와 실제 자동 실행 범위도 구분한다.

웹은 같은 이론·예제·퀴즈·설계 메모·편집기 및 프로젝트 ZIP을 제공한다. 실무 프로젝트 실행 버튼은 설치형에서 사용한다. 웹의 기존 Java 코어 실행은 Wandbox를 유지한다. 설치형 진도·초안·테마는 앱 데이터에 보존하고, 웹 진도는 브라우저에 보존한다. 기기 사이 자동 동기화는 제공하지 않는다.

구현자 외 독립 리뷰, 실제 기능 검사, 합성 화면 검수 후 마일스톤별 커밋·푸시한다. 완성된 프로토타입은 owner-private Sites에 배포한다. 공개 GitHub는 서비스 공개 권한과 구분한다.
